# 用语

| 用语 | 含义 |
| --- | --- |
| 发布源稿 | 人维护的 Markdown 与随文素材，HTML 从它们生成 |
| 正式内容 | 通过业内技术审核、已合并到 `main` 的文章，不等于公众号已发送 |
| 待审稿 | 公开 PR 内尚未收录的文章，预览和自动检查不代表人审通过 |
| 制作材料 | 可选提交的绘图代码、Notebook、原始数据、草稿及中间产物 |
| 最小证据记录 | `SOURCES.md` 中的来源、条件、指标口径和素材权利 |
| 参考屏 | 固定 390×844 CSS 像素视口内的正文屏高，含图与图注 |
| 指定审核者 | 产品名单内经人工确认专业资格、且不参与本文写稿的业内人士 |
| 品牌签名 | 识别公司来源的图形标识，不是审核人的签字 |
| 载体图 | 关注横幅、签名卡、阅读原文条这类随载体固定、不随文章内容变化的图片；与随文图分开管理 |
| 章节横幅 | 二级标题在公众号稿里换成的斜切缎带图，由构建按标题文字生成；预览稿保留可选中文字 |
| 案例卡 | 页尾指向配套案例二维码的卡片，内容来自 `series.json` 的 `case` 字段；缺该字段即不出卡 |
| 签名卡 | 页尾固定的联系方式与品牌标识卡片；不等于「品牌签名」，也不是审核人的签字 |
