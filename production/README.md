# 可选制作材料

投稿者可在 `production/<产品>/<系列>/` 附上可公开的生成脚本、Notebook 或小型数据样本，也可全部保留本地。正文与随文素材放在 `content/`，生成的 HTML 和截图放在被忽略的 `build/`。

文章无论是否附制作工程，都要有最小证据记录。审核所需的原始结果应能交由审核者核查；私人链接、云任务标识、凭据、费用记录和个人工具记忆留在本地。大型数据采用经授权的独立分发渠道，在文章记录稳定的公开来源；不要把完整仿真缓存提交进来。

附带第三方代码或数据时保留原许可，并说明取得途径。删除可选制作材料后，共享工具仍应能够从 `content/` 生成相同的发布排版。
