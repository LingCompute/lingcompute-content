# MMI 篇的最小证据记录

`mmi-mode-fdtd-evidence.json` 是第 3 篇（MMI）新增逐模 FDTD 实验的**脱敏数值记录**，供指定业内审核者核对正文中的模式、拍长、输出功率、监视器与随文素材指纹。

- 内容只含几何、波长、模式有效折射率、监视器口径、归一化读数、素材 SHA256 与制作口径；**不含**云端任务标识、FlexCredits 费用、API 凭据、私人链接、求解原始 HDF5 或工具日志。
- 原始 FDTD 结果（`MMI-mode-TE0/TE1/TE2.hdf5`）、截面模式求解数据和任务标识保留在本地制作工程，审核需要时由维护者另行提供，不随公开稿分发。
- 本目录不含第三方代码；正文与随文素材位于 `content/photon/power-splitters/`，其来源、指标条件和权利边界见该目录的 `SOURCES.md`。
- 删除本目录不影响从 `content/` 重新生成全部发布排版。
